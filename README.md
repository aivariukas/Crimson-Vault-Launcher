# 🔴 Crimson Vault Launcher

Hello everyone!

I'd like to share a project I've recently created: **Crimson Vault Launcher**.

## 📌 Why did I create this?

Recently, I ran into an issue with Rockstar Games while trying to launch **Red Dead Redemption 2**.

I was using a friend's Steam account to install the game, but Rockstar Games required a verification code sent to an email address that wasn't accessible at the time.

Instead of giving up, I decided to look for a solution. Using resources and information available online, I developed a tool designed to work around this launcher requirement.

## 🚀 Introducing Crimson Vault Launcher

I put together a fully packaged application with all the necessary resources included in a single ZIP archive.

**How to use it:**

1. Extract the downloaded ZIP archive.
2. Launch `Crimson Vault Launcher`.
3. Select your game.
4. Let the application automatically detect your game installation folder through Steam or Epic Games.
5. Click **Install Files**.
6. Launch your game and enjoy!

## ✨ Features

- 🎮 Simple and user-friendly interface.
- 🔍 Automatic game directory detection.
- 📦 All necessary resources included in one package.
- 🌐 Designed to work offline, without an internet connection.
- 🔑 No activation keys required.
- 💳 No subscriptions.
- 📥 No additional downloads required.

## ❤️ Final words

I created this project to make the process as simple and convenient as possible.

Everything is packaged together, so there's no need to deal with complicated installations or additional downloads.

Feel free to try it out, and I hope it works as well for you as it does for me!

**Enjoy!** 🔥

*Please make sure you own a legitimate copy of the game and respect the relevant game platform's terms of service.*
